# 성민복지관 지원회의 · 평생과정설계 기록 웹앱

장애인복지관 **평생과정설계(PPP) 지원사업**의 지원회의 과정을 관리하고, 참여자(장애 당사자)의 정보·서류·회의·실천 활동을 기록하는 웹앱입니다. 기관 PC에서 설치 없이 실행합니다.

> ⚠️ **데이터는 실행한 PC의 브라우저(IndexedDB) 안에만 저장됩니다.** 다른 PC·다른 브라우저·다른 직원과 **자동 동기화되지 않으며**, 저장 데이터는 **암호화되지 않고**, **로그인·다중 사용자 권한 관리가 없습니다.** 반드시 정기 백업하고 [SECURITY.md](SECURITY.md)를 확인하세요.

## 대상 사용자
- 평생과정설계 담당 사회복지사 (약 10명, 각자 업무 PC 사용)
- 당사자·보호자는 직접 사용하지 않으며, 빈 서식을 인쇄해 함께 작성할 수 있습니다.

## 주요 기능
| 기능 | 내용 |
|---|---|
| 대시보드 | 핵심 지표 5종, 원형 그래프(단계·장애유형·성별·지원연차·실천영역·회의유형), 막대 그래프(평가 점수·월별 기록·연령대·**지원회의 단계 간 평균 소요일**), **다가오는 지원회의**, 참여자별 진행상황 표, 확인 필요 알림, 최근 기록, 백업 알림 |
| 지원회의 | 회의 **일정 예약**(일시·장소·참석 역할·안건) → **결과 기록**(내용·결정 사항·확정 우선순위) → **다음 회의 바로 예약**, 지난 일정 알림, 전체 지원회의 목록·필터, **지원회의록 인쇄** |
| 참여자 관리 | 등록·수정·검색·필터·삭제(휴지통) |
| 진행단계 | 준비 → 계획(지원회의 5단계 + 단기계획) → 실천 → 평가 → 자조활동 연계, 회의 결과 기록 시 자동 완료 |
| 서식 | HWP 원본 그대로: 자기소개서(11개 장), 미래설계 실천계획서(연도별), 행복한 미래 이야기(연간 돌아보기) |
| 활동·평가 | 영역별 실천 활동, 월/분기/반기 활동평가 |
| PDF 출력 | 서식·회의록 「인쇄 / PDF 저장」, 빈 서식 인쇄 |
| 백업·복원 | JSON 백업, 검증 후 복원, 직전 상태 되돌리기 |
| 글자 크기 | 상단 「가−/가+」 4단계 |

## 실행 (기관 PC 로컬)
설치·서버가 필요 없습니다. Chrome 또는 Edge 최신 버전을 권장합니다.

**방법 A — 단일 파일 (권장)**
1. `dist/성민-평생과정설계.html` 을 PC의 고정 위치(예: `C:\성민\평생과정설계\`)에 복사
2. 더블클릭 → 브라우저에서 열림 → 바탕화면 바로가기/즐겨찾기 등록
3. **항상 같은 브라우저**로 여세요. 다른 브라우저로 열면 데이터가 보이지 않습니다.

**방법 B — 폴더 실행**: 폴더 전체를 복사하고 `index.html` 더블클릭

**단일 파일 다시 만들기** (코드 수정 후, Node.js 필요)
```bash
node scripts/build-single.js     # → dist/성민-평생과정설계.html
```
(선택) 웹 서버로 배포할 경우 `vercel.json`의 보안 헤더를 참고하세요. 단, 웹 배포해도 데이터는 각 브라우저에만 저장됩니다.

## 사용법
1. 처음 실행하면 **가상 샘플 데이터(14명)** 가 보입니다. 실제 사용 전 「설정 · 백업」 → 「모든 데이터 비우기」.
2. 「참여자」 → 「+ 참여자 등록」 (이름·담당자·지원 시작일 필수).
3. **지원회의 진행 흐름**
   - 참여자 화면 「지원회의」 탭 또는 왼쪽 메뉴 「지원회의」 → **+ 일정 예약** (다음 단계 회의 유형이 자동 선택, 안건 예시 표시)
   - 회의 후 해당 일정의 **결과 기록** → 회의 내용·결정 사항 입력, 확정회의는 영역 우선순위 1~3 선택
   - 같은 창 하단 「다음 지원회의 바로 예약」으로 다음 회의 일정까지 한 번에 저장
   - 결과 기록 시 진행단계가 자동 완료되고, 「회의록」에서 인쇄/PDF 저장
4. **서류**: 자기소개서 → 확정회의 후 실천계획서(연도) → 연말·연초 행복한 미래 이야기. 이전 서류 내용이 자동으로 채워집니다. `Ctrl+S` 저장.
5. 대시보드 「확인 필요」에서 지난 회의 일정, 다음 회의 미정, 서류 미작성, 평가 주기 경과를 확인합니다.

## 데이터 저장 및 백업 주의사항
- 저장 위치: 이 PC · 이 브라우저 · 이 사용자 프로필의 IndexedDB
- 데이터가 사라지거나 안 보이는 경우: 브라우저 「인터넷 사용 기록/사이트 데이터 삭제」, 시크릿 창, 다른 브라우저·PC·Windows 계정, PC 초기화, 디스크 부족 시 브라우저 자동 정리(설정 화면에 「영구 저장 허용」 여부 표시)
- **백업**: 「설정 · 백업」 → 「백업 파일 내려받기」. 7일 이상 백업하지 않으면 대시보드에 알림이 뜹니다. 권장 주기는 기관 정책 확인 필요.
- 백업 파일은 **암호화되지 않은 민감정보**입니다. 접근 권한이 지정된 기관 저장소에만 보관하세요.
- **복원은 현재 데이터를 교체**합니다(병합 아님). 직전 상태는 1회 되돌릴 수 있습니다.
- 담당자 변경·PC 교체 시: 기존 PC에서 백업 → 새 PC에서 복원.
- 이전 버전(localStorage 저장) 데이터는 처음 실행 시 자동으로 IndexedDB로 옮겨집니다.
